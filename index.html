Wilder Smoothing Mathematical Specification

1. Seed: Initial average gain and average loss are simple means of the first 14 session price changes (Day 2 to Day 15).
2. Smoothing Recursion: For each subsequent session, New Avg = (Previous Avg * 13 + Current Gain or Loss) / 14.
3. Relative Strength (RS) & RSI: RS = AvgGain / AvgLoss, and RSI = 100 - (100 / (1 + RS)). Edge cases: zero loss gives RSI 100; zero gain gives RSI 0; both zero gives RSI 50.

MACD Line, Signal Line & Histogram Series

EMA(12) of closes minus EMA(26) of closes, with EMA(9) signal line starting at close index 33 (session 34). Histogram H = MACD minus Signal.
Selected Name -- -- closes
Current MACD Line -- EMA(12) - EMA(26)

Current Histogram (H_t) -- H_t = MACD - Signal
Lagged Pair H_(t-N) -- histogramPair (N = 3)
MACD (12, 26, 9) Mathematical Specification

1. Fast and Slow EMAs: EMA helper seeded with simple mean of first N closes, then updated with multiplier 2 / (period + 1). Output starts at index period - 1.
2. MACD Line: EMA(12) - EMA(26) of closes, defined from close index 25 onward (session 26).
3. Signal Line: EMA(9) of the defined portion of the MACD line only, starting at MACD index 8, which is close index 33 (session 34).
4. Histogram H: MACD line - Signal line, defined from close index 33 onward (session 34). Full series is preserved for lookback evaluations.
